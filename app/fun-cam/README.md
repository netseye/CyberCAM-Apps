# 趣拍 (Fun Camera)

CyberCAM 上的多模式创意相机，三种玩法合一：**光绘 / AR 贴纸 / 体感快门**。

## 三种模式

| 模式 | 内容 |
| --- | --- |
| 1️⃣ 光绘相机 | 黑暗中用光源作画，逐帧叠加成光迹。中间触摸清空，长按保存。 |
| 2️⃣ AR 魔法贴纸 | 识别到脸自动贴眼镜/帽子/胡子，跟随移动与倾斜。中间触摸循环贴纸。 |
| 3️⃣ 体感快门 | 摇一摇触发拍照，画面叠加 AR 水平线辅助构图；中间触摸手动拍。 |

## 交互

- **触摸左/右**：上一/下一模式；**触摸中间**：模式内动作（清空/换贴纸/手动拍）。
- **板载按键 KEY**：下一模式。
- **M1 长按**：保存画布；**M3 摇一摇**：拍照（蜂鸣+白闪）。

## 文件

- `core.py` — 纯逻辑（姿态/摇拍/光绘/触摸/人脸几何），可在 PC 单测。
- `main.py` — 摄像头/显示/输入/三模式渲染/主循环。
- `qmi8658.py` — QMI8658A I2C 驱动（复制自 imu-attitude）。
- `face_detection_320.kmodel` / `prior_data_320.bin` — 人脸模型（复制自 face-det）。

## 部署

拷到 `/data/app/fun-cam/` 即可在系统 GUI 看到图标。调试：

    cd /data/app/fun-cam && python main.py    # Ctrl-C 退出

拍照/保存的图在 `/data/app/fun-cam/saved/`。
